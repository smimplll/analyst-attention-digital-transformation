# Analyst attention and corporate digital transformation

Исследовательский проект о связи внимания аналитиков с цифровой трансформацией российских публичных компаний в 2020–2024 годах.

В репозитории находится воспроизводимый эконометрический анализ. Код разделён на последовательные этапы.

## Главный результат

После учёта финансовых характеристик, отраслевых и годовых фиксированных эффектов внимание аналитиков не показывает устойчивой статистически значимой связи с индексами цифровой трансформации. Наиболее устойчивым фактором остаётся размер компании. Результат сохраняется после исключения влиятельных наблюдений и в моделях с фиксированными эффектами компаний.

## Что воспроизводит проект

- описательную статистику и графики распределений;
- корреляционную матрицу и три VIF-спецификации;
- шесть основных pooled OLS моделей;
- кластеризованные по компаниям стандартные ошибки;
- тесты Бройша–Пагана, RESET и кластеризованный RESET;
- нелинейную форму размера компании через natural spline;
- отбор наблюдений по Cook’s distance `> 4/n`;
- сравнение четырёх функциональных форм;
- модели на no-Cook выборке;
- альтернативные формы внимания и взаимодействие с размером;
- исключение 2022 года и отраслей Telecom/Retail;
- sector-year fixed effects;
- firm fixed effects + year fixed effects.

## Быстрый запуск

Требуется R версии 4.3 или новее.

```r
source("install_packages.R")
source("run_all.R")
```

Из терминала:

```bash
Rscript install_packages.R
Rscript run_all.R
```

Скрипты нужно запускать из корневой папки репозитория. Результаты появятся в `results/tables/` и `results/figures/`.

## Данные

`data/raw/panel_input.csv` — плоская панель из 300 наблюдений формата «компания–год». Она содержит только поля, необходимые для анализа: идентификаторы, два индекса цифровизации, показатели внимания, финансовые контроли и исходные величины для пересчёта отдельных контролей.

Ручные исправления не спрятаны в коде:

- `manual_corrections.csv` содержит компанию, год, переменную, новое значение и правило применения;
- `source_publications_by_year.csv` содержит годовые объёмы публикаций VTB, T-Invest и FINAM, используемые при нормировании внимания;
- `data_dictionary.csv` объясняет смысл и шкалу полей.

Скрипт `01_prepare_data.R` создаёт `data/processed/analysis_panel.csv`. Цифровые индексы переводятся в шкалу, использованную в курсовой, одним прозрачным преобразованием `index × 10`.

## Важное ограничение воспроизводимости

Проект воспроизводит эконометрический анализ начиная с подготовленной панельной выборки. Он не воспроизводит полный сбор текстовых данных с нуля, а также полный код их загрузки и текстовой обработки.
