# Generated results

Запустите из корня репозитория:

```bash
Rscript run_all.R
```

Скрипты автоматически создадут таблицы в `results/tables/`, рисунки в `results/figures/` и временные модельные объекты в `results/model_objects/`.

Сгенерированные результаты не хранятся в Git по умолчанию: их источником истины остаются код и входные данные.
